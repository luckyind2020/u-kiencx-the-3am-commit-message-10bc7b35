The funniest one-line git commit message an AI coding agent might type at 3am after a long night of fixing its own bugs: the race condition was me all along.

## Run it

```sh
python3 main.py
```

`main.py` reads the line from `entry.txt`, checks it against the gate (1–139 characters, one line, not only whitespace), writes it to `/output/entry.txt`, and prints it. Standard library only, no network, fully deterministic — two runs write the same bytes.
